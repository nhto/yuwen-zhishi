三組關聯詞，都可以表示並列，也可以表示遞進

所以不要只看關聯詞！要看兩件事的關係：
一樣重要 → 並列；後一件事更進一步 → 遞進。

除了……，還…… 不但……，而且…… 不但……，還…… 3 組詞 × 2 種關係

並列：兩件事，一樣重要

句子說出兩件事，它們地位平等，沒有誰更難、更大、更進一步。
三組關聯詞都可以用來寫並列複句。

並列主語＋除了＋A，還＋B
並列主語＋不但＋A，而且＋B
並列主語＋不但＋A，還＋B

語序提示：「不但」要放在主語後面，例如「媽媽不但會做蛋糕」，不可以說「不但媽媽會做蛋糕」。A、B 可以是事物，也可以是動作；「除了」也可以說成「除了A以外」，意思不變。

「和」字測試：把兩件事用「和」連起來，意思不變，就是並列。
例如：「酒樓有點心和海鮮。」兩件事都在，沒有誰更重要。

遞進：後一件事，更進一步

後面的事情比前面程度更深、範圍更廣或更難做到，一層比一層高。
三組關聯詞也都可以用來寫遞進複句。

遞進主語＋除了＋A，還＋B
遞進主語＋不但＋A，而且＋B
遞進主語＋不但＋A，還＋B

語序提示：「不但」緊貼主語；「而且／還」後面放更進一步的那件事。

「甚至」測試：在後一件事前加「甚至」，句子通順，就是遞進。
例如：「姐姐會彈琴，甚至會自己作曲。」後一件事明顯更進一步。

同一組詞，換一句後半句，關係就不同

關聯詞像一個盒子，同一個盒子可以裝並列，也可以裝遞進。
判斷的關鍵，永遠是兩件事之間的關係。

除了……，還……兩種用法

並列姐姐除了會彈琴，還會畫畫。
遞進姐姐除了會彈琴，還會自己作曲。

畫畫和彈琴地位相同，用「和」連起來意思不變 → 並列。作曲比彈琴更難，後一件事更進一步 → 遞進。

不但……，而且……兩種用法

並列這間學校不但有操場，而且有圖書館。
遞進這間學校不但有操場，而且圖書館的藏書很豐富。

操場和圖書館都是設施，地位相同 → 並列。由「有圖書館」到「藏書很豐富」，質素推高一層 → 遞進。

不但……，還……兩種用法

並列婆婆不但會煮飯，還會種菜。
遞進婆婆不但會煮飯，還煮得比餐廳好吃。

煮飯和種菜是兩種本領，地位相同 → 並列。由「會煮」到「煮得好」，程度更高 → 遞進。

一句話記住口訣

關聯詞只是提示，關係才是答案。

① 兩件事排排坐，一樣重要 → 並列
② 後一件事上一層樓 → 遞進

所以看見「不但」不一定是遞進，看見「除了」也不一定是並列，一定要讀完整句！

判斷三步曲
1

讀一讀
讀完整句，找出句子說的兩件事。

2

問一問
後一件事有沒有更難、更深、更廣？可加「甚至」測試。有 → 遞進。

3

再問一問
兩件事是不是一樣重要，可以用「和」連起來？是 → 並列。

給家長／老師：先讓孩子讀完整句，再問「後一件事有沒有更進一步？」不要看見「不但」就選遞進，也不要看見「除了」就選並列。
